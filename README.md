# Generalised-Data-Structures-Library
A reusable C++ library implementing various linear and non-linear data structures using generic programming techniques.

## Project Overview
Generalized Data Structure Library is a C++ template-based library that implements multiple data structures using generic programming concepts. The project provides reusable and type-independent implementations of commonly used linear data structures.

This library demonstrates:
- Generic Programming using Templates
- Object-Oriented Programming
- Dynamic Memory Management
- Linked List Implementations
- Stack and Queue Operations

The project is designed to work with multiple data types such as:
- Integer
- Character
- Float
- Double
- User-defined data types
